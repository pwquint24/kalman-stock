#+title: Kalman Filtering vs. ARMA Models for Stock Forecasting
#+author: Andrew Patrick
#+language: en

A comparative framework in Wolfram Language for extracting dynamic trend
from stock prices and forecasting future prices, using two distinct
mathematical paradigms: classical ARMA econometrics and Kalman
state-space filtering.

* Overview

Predicting future stock prices and extracting dynamic trends are two
foundational problems in quantitative finance. This project implements
and rigorously compares:

1. *ARMA models* (Box-Jenkins) -- fit to stationary continuously
   compounded log returns, then projected forward toward the
   unconditional drift rate.
2. *Kalman filtering* (Local Linear Trend state-space model) -- estimates
   unobserved hidden states (trend level and momentum) from noisy
   sequential observations, updating recursively with optimal Bayesian
   variance reduction.

The research question: how accurately can each model predict the
*expected average price* over an investment horizon (e.g. a 20-day
trading month)?

* Mathematical Specification

** ARMA on Log Returns

Prices are \(I(1)\) and non-stationary, so we model log returns instead:

\[
r_t = \ln(P_t / P_{t-1})
\]

An ARMA(p, q) process for returns, reconstructed to a price path:

\[
P_{T+h} = P_T \exp\!\left(\sum_{i=1}^{h} r_{T+i}\right)
\]

** Local Linear Trend Kalman Filter

Observation equation and state transitions for level \(\mu_t\) and
slope \(\beta_t\):

\[
y_t = \mu_t + \epsilon_t, \quad
\mu_{t+1} = \mu_t + \beta_t + \eta_\mu, \quad
\beta_{t+1} = \beta_t + \eta_\beta
\]

Forward extrapolation is analytic, giving the expected average price
over horizon \(H\):

\[
\bar{P}_{\text{Kalman}} = \mu_T + \frac{H+1}{2}\,\beta_T
\]
